## Tecnologia escolhida

O **GeoPoints** é uma aplicação web desenvolvida com **React, JavaScript, HTML5 e CSS3**, utilizando o **Vite** como ambiente de desenvolvimento e o **React Router** para a navegação entre páginas.

O sistema realiza operações de cadastro, listagem, consulta, edição e exclusão de pontos geográficos (CRUD), por meio da integração com a **GeoPoint API REST**, utilizando Fetch API e JSON.

A interface é responsiva, baseada em um protótipo desenvolvido no **Figma**, e conta com integração ao **OpenStreetMap** para visualização das localizações.

O versionamento e a colaboração no projeto são realizados por meio do **Git e GitHub**.

## Como rodar o projeto

É necessário ter o Node.js instalado, em uma versão compatível com o Vite utilizado no projeto.

Clone o repositório:

```bash
git clone https://github.com/Antony0806/TrabalhoGeoPoint.git
```

Entre na pasta:

```bash
cd TrabalhoGeoPoint
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Abra o endereço informado pelo Vite no navegador (normalmente http://localhost:5173).
